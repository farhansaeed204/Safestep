# SafeStep

An offline Android app that uses the phone camera as a guiding eye for blind and
low-vision users. v6 detects people, vehicles, animals and furniture with a strict
COCO-only pipeline, then warns the user with **voice (Urdu/English)**, **vibration**,
and **directional beeps** when something is close. Wall/stairs/gate detection is
planned for the next version.

> This is a hackathon MVP. Distances are estimates, not safety-critical measurements.

A public landing page with the APK download lives in [`landing/`](./landing)
(Next.js + Tailwind CSS).

## What works today

- Expo + React Native + TypeScript app (Expo SDK 58, React Native 0.88).
- Home / Navigation / Settings screens with large, screen-reader-friendly controls.
- **Demo mode** that simulates a car, dog, person and chair so the entire alert
  pipeline can be tested without any AI model.
- Real camera pipeline (VisionCamera v5 + GPU resizer + TFLite):
  - YOLO11 COCO model. People, vehicles, animals and furniture are announced;
    other COCO objects (laptop, bottle, phone, etc.) are shown visually.
  - Strict class-margin, cross-class duplicate suppression, 50 m range cap and a
    4/6-frame temporal tracker. Center-only filtering is off by default.
  - Worklet decoder with per-class NMS, monocular distance estimate and left/center/right zone.
- Flashlight toggle with an accessible camera-screen button and spoken “light on/off”.
- Feedback engine:
  - Offline TTS in Urdu (`ur-PK`) or English (`en-US`).
  - Vibration patterns that get faster as the obstacle gets closer.
  - Stereo beeps: left / center / right WAV files (generated by `scripts/gen_sounds.py`).
- Push-to-talk voice commands: “stop”, “repeat”, “describe”, “help”, “light on/off”
  (English + Roman Urdu).

## Requirements

- Node.js 20+ (tested with 24) and npm.
- An Expo account (free) for cloud builds — **no Android SDK required locally**.
- An Android phone with at least 3 GB RAM.

**Demo mode works in Expo Go.** Camera mode and voice commands require a Development
Build because VisionCamera, TFLite and speech recognition contain custom native code.
The app detects Expo Go and falls back to demo mode automatically.

## Quick start

```bash
npm install
npm run typecheck
npm run lint

# Start Metro (then build/install the dev client with EAS)
npx expo start
```

### Build a Development Build (cloud, free)

```bash
npm install -g eas-cli        # or use: npx eas-cli@latest
eas login
eas build -p android --profile development
```

Download the APK from the EAS link, install it on the phone, then run `npx expo start`
and open the app. It will connect to Metro.

### Build a shareable APK

```bash
npm run build:apk             # eas build -p android --profile preview
```

## Landing page

The marketing/download site is a separate Next.js app in `landing/`. It does not
affect the Expo app.

```bash
cd landing
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

Set the download link in `landing/lib/site.ts` (any URL works — EAS, MediaFire,
or your own host):

```ts
export const APK_URL = "https://your-download-link";
```

Deploy on Vercel by importing this repository and setting **Root Directory** to
`landing`.

## Demo mode vs camera mode

- **Camera mode** (default): uses the bundled COCO model for live detection.
- **Demo mode**: no models needed. Simulated obstacles exercise voice, vibration
  and beeps. Great for a first run and for the judges.

If camera mode cannot load the models, the app shows an error card with a demo
mode button and on-screen diagnostics.

## Calibration

All tuning knobs live in `src/config.ts`:

| Setting | Meaning |
| --- | --- |
| `verticalFovDeg` | Portrait vertical field of view. Lower if objects seem too close. |
| `cameraHeightM` | Phone height while walking (ground hazard distance). |
| `horizonNorm` | Horizon line position in the preview (0–1). |
| `candidateThreshold` | Raw model candidates below this are discarded (default 0.35). |
| `displayThreshold` | Detections below this score are hidden (default 0.35). |
| `voiceThreshold` | Confirmed tracks below this are not spoken (default 0.65). |
| `centerBand` | Middle fraction of the frame kept when center-only is on (default 0.40). |
| `maxDistanceM` | Detections farther than this are ignored (default 50 m). |

## Troubleshooting

- **Camera mode / voice commands unavailable in Expo Go** — expected; use a Development
  Build. Demo mode runs in Expo Go.
- **“AI models not loaded” error** — check the diagnostics text on the card, then
  retry or use demo mode.
- **Urdu voice is silent** — install/update Google Text-to-Speech and an Urdu voice
  in Android settings, or switch the app language to English.
- **Left/right feels reversed** — hold the phone upright in portrait; frames are
  rotated to match the screen orientation automatically.
- **Detections are slow** — lower `CAMERA.targetWidth/Height`, keep `enablePreviewSizedOutputBuffers`,
  or enable the NNAPI delegate in `useObjectDetection.ts`.
- **Still seeing false positives** — open Settings, keep center-only on, raise confidence,
  lower the detection range, and use the debug overlay to inspect raw/filtered counts.
  COCO cannot guarantee zero false positives; the next-version hazard model is the longer-term fix.
